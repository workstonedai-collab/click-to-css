# Agent development notes / Agent 开发说明

Read both READMEs and CONTRIBUTING.md before making changes. Keep changes scoped and preserve others' work. Run npm test and the relevant local demo. Use synthetic fixtures. Do not commit secrets, generated output or local task state. Document behavioral limits explicitly; do not claim broader verification than was performed.

修改前先阅读双语 README 和贡献指南。保持范围清晰，保留他人的修改，运行测试及相关演示，使用合成样例。不得提交密钥、生成结果或本地任务状态。说明功能边界，验证结论须符合实际检查范围。
