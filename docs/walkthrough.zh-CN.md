# 从点选网页到修改 CSS 源文件

[English](walkthrough.en.md) · [项目概览](../README.zh-CN.md)

**先在自带静态页面中完成一次真实修改，再撤销。** 需要 Node.js 22.12+、浏览器和约五分钟；无需账号、AI 服务或 API 密钥。

## 1. 启动示例

```sh
git clone https://github.com/workstonedai-collab/click-to-css.git
cd click-to-css
npm ci
npm run dev
```

打开 Vite 打印的地址，并在后面加 `/__click_to_css`，通常是 `http://127.0.0.1:5173/__click_to_css`。端口被占用时，以实际打印的端口为准。保持服务仅在本机访问。

## 2. 点选标题

点选左侧的 **Make the page feel right. / 让页面恰到好处。**，在右侧设置：

- 源规则：`style.css · h1 [0]`。
- 属性：`font-size`。
- 初始值：`52px`。

![点选标题与初始字号](walkthrough-selected.png)

录屏使用宽窗口。示例在宽度小于 800px 时通过媒体查询使用 `34px`，请扩大窗口以复现这里的数值。

## 3. 预览 46px

输入 `46px`，点击「预览」。标题的显示发生变化，源文件仍保持原样。保存前可以继续尝试其他数值。

## 4. 保存到真实文件

点击「保存 CSS」。插件修改真实 `style.css` 中选定的 `h1` 声明。页面重新载入后会清除选中状态；再次点选标题即可查看新数值。

查看文件差异：

```sh
git diff -- style.css
```

关键变化应是：

```diff
 h1 {
-  font-size: 52px;
+  font-size: 46px;
```

![保存后再次选中标题，查看真实的 46px](walkthrough-saved.png)

保存会修改共享规则，其他匹配同一选择器的元素也可能变化。提交前请查看差异。

## 5. 撤销并确认

点击「撤销」，标题恢复原始大小。再次运行 `git diff -- style.css`：如果开始时文件干净，且仅执行了上述操作，应不再显示修改。

撤销记录属于当前开发服务会话。如果其他编辑器改过文件，工具会拒绝覆盖较新的内容。长期历史请交给 Git 或人工审阅。

## 下一步：接入自己的页面

按照[接入已有目录的说明](../README.zh-CN.md#接入已有目录不搬动原页面)，仅登记需要编辑的 HTML 和普通外部 CSS 文件。当前版本未实现 React/Vue 组件源码、Tailwind 类名或 CSS-in-JS 映射。
